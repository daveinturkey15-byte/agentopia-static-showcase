Replay review checklist

  • Fixture provenance: confirm catalog title/path or local file name before trusting evidence.
  • Story and event evidence: inspect the story recap and event log for the intended chat, note, quest, decoration, movement, or collision beats.
  • Participant and final-state evidence: check participants, metadata, state summary, cell inspector, notes, and quest panels for the final observable state.
  • Local-only boundaries: this review does not upload files, edit replays in the browser, host a public demo, or add quest completion/rewards.
